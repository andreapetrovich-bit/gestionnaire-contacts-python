# Gestionnaire de contacts

## Description 

Application développée en Python permettant de gérer un répertoire de contacts depuis un terminal.

## Fonctionnalités

- Ajouter un contact
- Afficher tous les contacts 
- Rechercher un contact par son nom
- Modifier les informations d'un contact 
- Supprimer un contact
- Sauvegarder automatiquement les contacts dans un fichier JSON
- Charger les contacts au démarrage du programme

## Installation et utilisation 

### Prérequis 

- Python 3 installé sur l'ordinateur 

### Lancement 

Ouvrir un terminal dans le dossier du projet, puis exécuter : 

```bash
python3 main.py
```

Le menu du gestionnaire de contacts apparaît.
